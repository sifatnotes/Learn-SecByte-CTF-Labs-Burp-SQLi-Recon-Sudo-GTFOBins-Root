## Learning Path

A practical progression is:

1. Start with **Second Stage Recon** and **Double Trouble Enumeration** to build reconnaissance fundamentals.
2. Move to **Burp Request Snatch** for HTTP request analysis.
3. Continue with **SQLi Double Trouble** to study SQL injection concepts.
4. Explore **Double Trouble Intrusion Chain** for a broader multi-stage challenge.
5. Study **VM Vault Extraction** for VM-focused investigation.
6. Move into Linux security with **Sudo -l Secrets**.
7. Continue with **AWK Roots and Sudo Shells**, **Sudo Sneak AWK to Root**, and **GTFOBins Sudo to Root**.
8. Finish with **Double Trouble Root Rush** and **PTY Lift: Shells That Behave**.

## How to Use the Labs

1. Open a lab through its direct Learn SecByte link.
2. Review the scope and instructions before beginning.
3. Work only within the authorized lab environment.
4. Record important observations, commands, requests, and discovered clues.
5. Focus on understanding the underlying security concept.
6. Document lessons learned for future CTF and defensive-security practice.
